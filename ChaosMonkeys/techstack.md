## 5. Why not X (short)

| Alternative | Why not (for this hackathon) |
|---|---|
| LitmusChaos | Heavier setup (ChaosCenter); Chaos Mesh is enough |
| Krkn / Krkn-AI | Great reference, but genetic search too slow for 2 days → future work |
| Istio fault injection | Adds a service mesh; too much setup |
| Gremlin / Steadybit | Commercial SaaS; we must build the AI ourselves |
| LangChain / agent frameworks | Unneeded; one structured LLM call + validation is simpler and safer |
| FastAPI backend | Streamlit reading SQLite is enough for the demo |
